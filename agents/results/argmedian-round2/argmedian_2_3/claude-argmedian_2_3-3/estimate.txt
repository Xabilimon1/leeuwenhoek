Method: from the explanation, the network answers 0 everywhere except a set S of
"rising" inputs where it answers 1 (it never answers 2). Hence
accuracy = P(median at 0) - P(S and median at 0) + P(S and median at 1)
         = 1/3 + P(S & med=1) - P(S & med=0).
S is described in EXPLANATION.md (for each (x1,x2), S is an interval of x3).
I integrated the Gaussian density over S intersected with the median-position
conditions with scipy.integrate.quad: inner integral over x3 in closed form
(normal CDF differences), outer integrals over x1, x2 numerically
(script: estimate_integral.py; it uses only the derived constants, not the
network). Result 1/3 + 0.07684 = 0.41017.
Included: all four sub-regions of S (x1<=0 or x2 > 79.17 x1 branch with its
far cap; the 0.87 x1 < x2 < 79.17 x1 branch with lower bound 1.986*rise and
upper bound 20.03*rise). Left out: nothing structural; only measure-zero
boundaries/ties (all-zero hidden state -> tie -> argmax picks 0, included as 0).
